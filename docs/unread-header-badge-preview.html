还剩一件小事要你拍：红点跟「区」字压多少——下面 ② 里 C1 / C2 两种，其余（尺寸、数字、状态）我已按建议定好，你扫一眼有没有要改的。

实现后发现的两条真实约束（这个预览页模拟不出来，真机 CSS 才有）：
  1. .sectionHeader 高 36px 且 overflow:hidden；里面的 .sectionLabel 行高 20px，它自己也 overflow:hidden。所以红点不能挂在标题元素里往上探——会被标题自己的 overflow 裁掉。实现改成：红点挂在标题行上、与标题平级，用实测 rect 定位，top 夹到 ≥0（只有 8px 余量）。看起来仍是 C1 的样子，但命中区改为 15px 本体 + 只向左右和下方外扩。
  2. 点搜索时标题会塌成 0 宽（.sectionLabelHidden），红点作为兄弟节点借不到它的 visibility，所以搜索展开期间红点会自己隐藏。
